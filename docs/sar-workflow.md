# 从结构到 SAR 结论：实施顺序与验收

每一步保留可回溯输入和输出；复用现有模块，逐步交付，不把候选解释当成实验结论。

| 步骤 | 交付与验收 | 当前情况 |
|---|---|---|
| 1. 统一证据 | 每条观测连接结构、文档、编号、实验、原始值、限定符、定位、质量标记、复核状态；缺失不能变成零 | 已完成本地已整理数据适配和台账页面；通用文献提取、原文定位补录和独立复核待完成 |
| 2. 结构变化 | 明确共同骨架、替换位置、片段 A/B；记录对称歧义、多位点变化和桥连 | 已接入统一台账；选择文献/专利的 A、B 两个分子进行共同锚点和 R 片段对齐 |
| 3. 测量可比性 | 同来源、同 assay、条件及终点一致、已知量纲的正精确值暂定数值可比；缺证时不计算 | 已接通逐项检查、B/A、排除原因与原始来源；跨来源协议和独立科学复核仍待完成 |
| 4. SAR 汇总 | 按骨架/位点/替换/终点汇总支持、反例、未测和独立来源数，保留所有分子对 | 已接通 1–8 个用户所选分子对的分组汇总；去重正反向对照，多位点/桥连及不可比测量列为未纳入项 |
| 5. 证据审查 | 检查结论与原始记录一致、缺失与限定值处理、跨实验误比较、因果越界；独立专家复核单独记录 | 已接通规则审查及本机追加保存人工复核记录；证据变化后不沿用旧复核，自动通过不等于化学家通过 |
| 6. 改造建议 | 从输入结构输出有适用条件、来源、反例及验证计划的方向；证据不足明确弃答 | 已接通本批 A 精确结构匹配、具体 assay 与数值方向的已有 B 候选；保留反向案例并在无证据时弃答，不外推到新分子 |

## 第一步的实际交付

启动服务后打开 `/evidence`，或点击工作台顶部“证据台账”。`GET /api/evidence` 提供完整 JSON，可按来源、分子/实验和测量状态筛选并下载。

当前范围为两份固定论文和两份专利：37 条结构记录（未跨来源去重），320 条观测，包括 285 条精确值、26 条限定或关系未知值、9 条缺失记录。论文数据保留 ChEMBL 原始 CSV 各字段，专利保留测量原文及未测原因。原文件 SHA-256 随导出保存，专利原始 HTML/PDF 已记录的哈希也保留；构建台账不会联网重新核对上游快照。

论文 296 条观测缺少逐条原图/表格定位及完整协议核对；320 条记录均待独立复核。这些缺口显式导出，不用数据库可点击链接代替原文审核。页面汇总固定已整理包，不自动包含当前在线检索结果，也不产生改善结论。

## 第二、三步操作

在 `/evidence` 点击“② 结构对齐”，选择来源范围及不同 A/B 分子，点击“分析结构变化”。结果保留共同锚点覆盖率、匹配歧义、R 标签变化、桥连提示和结构来源。对齐返回后点击“③ 检查所选分子的测量”，查看全部实验或筛选某个 assay，下载本次 JSON。

试用文献 CHEMBL3286195 的 6e（CHEMBL3286809）与 6f（CHEMBL3286810）。专利 WO2011138751A2 的 Example 6/7 可以验证缺失细胞测量不算倍数。切换选择立即清空旧结果，后端拒绝规范化后相同结构。

可比性依据现有记录中的来源、assay ID、实验描述、终点、单位和质量标记，未独立抽取或验证全部靶点/物种/突变元数据。跨来源、协议差异、重复观测、限定值、缺失项、未知量纲、非正或无效值均不计算比值。相同协议内的 B/A 也只是暂定数值对照，不能直接当作改善、单点因果或历史优化步骤。第四至六步已提供所选分子对范围内的工作流，尚非全库自动 SAR 挖掘。


## 第四至六步操作及边界

1. 第③步完成后，在④点击“加入当前已检查分子对”。可继续选择其他 A/B，重复②③，再加入本批，最多 8 对。点击“汇总本批替换效果”。批次保存在本次页面会话中，刷新会清空；可下载分析 JSON 留档。
2. 分组键包含本次带标签共同核心、R 标签、A→B 片段、来源文档、assay 和终点。不同核心或协议不强行合并；重复及反向选择不增加支持数。此保守分组可能拆开化学上等价的对齐，不能用零跨组支持断言某替换没有其他证据。
3. ⑤展示结构阻断与原始证据缺口。填写复核人、结论和理由可保存；记录及被复核报告保存在 `artifacts/sar-reviews/<report_id>/`，不提交 Git。记录为用户声明，不验证复核人身份，不改写原始数据审核状态。证据哈希变化时旧复核不适用。
4. ⑥填写目标 SMILES（或“填入当前 A”），选择具体 assay 和期望数值方向。仅对本批中精确匹配 A 的已记录 B 输出待验证方向；不会将替换规则移植到任意新骨架。最新复核为拒绝或待补证据时暂停候选输出；尚无人工复核或接受有限结论时仍显示全部缺口。
5. 选择 CHEMBL3286195 的 A=6f、B=6e，可在 CHEMBL3293161 的降低目标下看到候选。在 CHEMBL3293391（MDR1 外排比）的降低目标下则保留相反方向案例：酶活性有利、外排不利。不同实验的结果并列，不能据单个终点推断整体更优。

`POST /api/sar-workflow` 支持 `summary` / `review` / `suggest` 模式。服务器从已整理证据重新计算，不信任客户端提交的分组、倍数或审核状态。下载包含所用快照、原始证据、未纳入项、复核记录及本次建议。未考虑实验误差/统计显著性，未完成独立化学家验证；自动审查为确定性规则检查，未调用大模型。
