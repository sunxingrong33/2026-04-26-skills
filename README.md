# SAR Evidence Explorer

从公开论文数据重建可追溯的结构与测量对照，生成待核验的 SAR 候选假说。目前是研究原型，**不是经过科学验收的竞对研发意图识别系统**。

## 输入专利号

```sh
python -m pip install -r requirements.txt
python -m phase0.sar.serve
```

打开 http://127.0.0.1:8766/ ，输入完整公开号（例如 WO2013132376A1）并点击检索。服务只绑定本机，需要联网读取新专利。首次请求保存原始 HTML、SHA-256、读取时间与解析 JSON；后续读取 `artifacts/patent-cache/` 的来源快照。不会用演示数据替代失败请求。

可以继续添加其他专利、点击同族或引用公开号检索，按页面记载的优先权日并列查看。每份专利显示可识别的实施例段落、自动化学实体索引和来源；索引结构可选作 A/B，计算结构描述符及 MCS 差异。可下载当前证据 JSON。

### 第一组实施例证据卡

`WO2013132376A1` 新增 Examples 2、4、6 的逐项转录包：最终产物结构图位于 PDF 第 260、264、268 页；12 条测量来自第 436 页 Table 1 的对应行，实验协议位于第 435–436 页。页面提供“分子证据卡”，可以选择 A/B 并查看结构与同协议测量差异，以及逐行原文链接。

转录由助手目视核对 PDF 完成，状态为 `agent_visual_checked_pending_independent_review`，不是独立化学家验收。三个 WT Ki 的 `<0.200 nM` 保留为上限，不参与倍数计算。Example 4 的SFC 分离信息保留为限制，不为未指定峰赋值。数值关联可以支持待复核的候选解释，不能证明作者意图、因果关系或历史先后。

数据包位于 `phase0/data/patent_evidence/WO2013132376A1.json`，记录 HTML/PDF 哈希、页码、实施例、SMILES、测量及复核状态。HTML 快照哈希改变时暂停使用映射；同族专利不自动继承实施例编号。该功能目前只覆盖这 3 个实施例，不是任意专利的自动结构识别。

**边界**：日期排序不是已确认的研发路线；同族公开不是新一代。化学实体可能包含试剂、背景结构和中间体，尚未自动对应实施例、实验活性与研发意图。OCR 实施例标题可能漏检；公开号不存在、访问限制与来源格式变化会明确报错。SMILES/靶点检索、结构 OCR 和自动跨专利路线仍未实现。

## 快速复现固定案例

Python 3.10+，从仓库根目录执行：

```sh
python -m venv .venv
# Windows: .venv/Scripts/activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -q
python -m phase0.sar.demo
```

打开 `artifacts/sar-explorer.html`，或通过 `phase0/web/index.html` 的入口进入。自包含页面可离线查看，生成过程不需要 API key，不调用大模型。包含论文系列浏览、结构差异高亮、同 assay 测量对照、证据抽屉、来源链接和验证状态。

## 已实现

- 浓度单位统一；不兼容单位拒绝比较；assay/type 不一致不计算活性倍数；LogD 等对数指标不报告原始值相除。
- 重复测量先按化合物取中位数，支持数按独立化合物计算。
- 叙述响应 schema 校验、有限重试、逐条引用与数字检查；标题仅取保留候选；全部丢弃时标记证据不足。
- 每个生成结果保存 FACTS 快照，评测优先使用快照，避免证据编号漂移。
- ChEMBL 文献范围导入、缓存、分页保护、离线重建；不自动推断专利映射或研发顺序。
- 冻结规则验证、人工复核表、旧复核表归档、离线证据页面。

**有效引用编号不等于结论有据，数值相同不等于推理正确**。规则分值不是概率，MCS 高亮不证明药效团或因果关系。

## 验证现状

冻结原有 21 条规则，未依据留出结果调参。开发案例生成 8 条候选，目标关键词命中 1/3；独立案例生成 2 条候选，命中 0/2。这些只是诊断代理指标，不能当作真实召回率。

`artifacts/validation/` 保存数据/规则哈希、FACTS、候选、`claims_review.csv`、`objectives_review.csv`。每行需要填写 yes/no、复核人和理由，全部完成后才计算对应人工指标，否则为 null。同一快照的复核会保留；数据变化时旧表自动归档。

目前仅一个独立程序，原文逐项核对和独立化学家复核尚未完成，`release_ready` 保持 false。LLM API 路径有模拟回归测试，未做真实模型性能评测。
