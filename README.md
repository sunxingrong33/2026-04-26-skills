# SAR Atlas · 专利与文献证据工作台

从专利公开号出发，查看专利家族、优先权日期、实施例和结构；对已整理的分子证据卡，比较结构与原始测量，并回到 PDF 核查。

项目目标是构建“竞对 SAR 演化时间线”：输入化合物、专利号或靶点，输出结构与属性变化，以及有证据支撑的研发问题假说。**当前完成的是公开号、SMILES 与靶点检索入口、两组专利实施例证据卡、跨家族关联案例和固定文献对照，仍是研究原型。** 任意专利自动抽取和经过证据确认的历史演化路线尚未实现。

## 当前能力

| 功能 | 当前状态 |
|---|---|
| 输入完整专利公开号 | 已实现；读取 Google Patents 公共页面，支持继续检索同族和引用专利 |
| SMILES 输入 | 本地 RDKit 解析、二维结构与描述符、6 张专利证据卡的规范化异构 SMILES 匹配；可选 ChEMBL 标准 InChIKey 查询 |
| 靶点输入 | ChEMBL 名称 / 基因符号 / ID 查询；用户按物种与类型选择，再分页查看分子、测量及来源 |
| 专利日期与家族 | 按来源记载的优先权日排列；跨专利关联视图合并同族公开 |
| 实施例原文与化学实体索引 | 自动提取支持格式的文本和可解析结构；标题可能漏检，结构可能包含试剂与中间体 |
| 结构—实施例—活性证据卡 | 显式整理两份专利，共 6 个实施例、22 项原始测量；另有 2 项细胞测量保留未测状态 |
| A/B 分子对照 | MCS 高亮、RDKit 描述符差异；同一分子不能同时选为 A 和 B，后端拒绝相同结构对照 |
| 活性对照 | 同专利匹配协议的精确值可计算 B/A；限定值不算倍数；跨专利只并列展示原始值 |
| 跨专利关联 | 一个已整理的双家族案例，分开展示事实、研究假设和证据缺口；不认定直接演化 |
| 来源文档 → 专利候选 | 解析当前测量页的真实文档，区分论文与专利；有效公开号一键核实加载，按已核实家族归组并保留来源链 |
| 来源追溯 | 原文/PDF 链接、实施例及表格定位、快照哈希、读取时间、当前专利证据 JSON 下载 |
| 固定文献案例 | 31 个结构的离线页面，含系列浏览、结构与测量对照、来源及验证状态 |

## 快速开始

需要 Python 3.10+，以下命令在仓库根目录执行。常规工作台和离线案例不需要模型 API key。

```sh
python -m venv .venv
```

激活环境：

```powershell
# Windows PowerShell
.venv\Scripts\Activate.ps1
```

```sh
# macOS / Linux
source .venv/bin/activate
```

安装依赖并启动：

```sh
python -m pip install -r requirements.txt
python -m phase0.sar.serve --port 8766
```

打开 [本机工作台](http://127.0.0.1:8766/)。服务只绑定本机，关闭服务后页面接口不可用。

### 推荐体验流程

1. 点击 **加载跨家族证据案例**，读取两份公开专利并进入“跨专利关联”。首次读取需要联网。
2. 查看按优先权日排列的两个家族，以及关联事实、研究假设和缺少的证据。
3. 点击 **对照早期 Example 7 与大环 Example 6 →**，查看结构差异与原始活性值。
4. 切换到 **分子证据卡**，自行选择不同分子为 A、B；底部选择栏显示当前分子，点击 **查看 A/B 对照 →** 后计算。
5. 点击结构图、活性表的来源链接，核对原始 PDF；在“家族与来源”下载当前专利的证据 JSON。

也可以在输入框直接填写完整公开号，例如 `WO2013132376A1`。其他专利可检索文本和结构索引，但只有已整理且来源匹配的专利才有证据卡，不会按结构索引顺序编造实施例映射。

原始 HTML、SHA-256、读取时间及解析 JSON 缓存在 `artifacts/patent-cache/`，后续请求优先使用缓存，**不会自动保证上游内容为最新版本**。网络、校验或解析失败会显示错误，不用样例替代。来源 HTML 哈希改变时，旧证据映射停用并等待重新核对。原始 HTML/PDF 缓存不提交到仓库。

### SMILES 与靶点入口

输入框左侧可切换“专利号 / SMILES / 靶点”。

- **SMILES**：粘贴结构或点击“填入洛拉替尼 SMILES”，然后检索。默认只在本地解析并匹配已整理的专利证据卡；勾选“同时查询 ChEMBL”或点击结果中的查询按钮后，才向 ChEMBL 发送标准 InChIKey。命中记录后可查看相关测量与靶点。本地匹配保留立体信息；标准 InChIKey 可能合并互变异构形式，当前未做相似性、子结构或去盐检索。
- **靶点**：输入 `ALK`、`EGFR` 等名称/基因符号，或 `CHEMBL4247` 等 ID，查询 ChEMBL。先选择候选的物种和靶点类型，再查看测量。人源 ALK 另提供已整理双家族案例入口，不代表该靶点的完整专利清单。
- **测量结果**：每页最多 20 条，按 activity_id 排列，可翻页；保留限定符、缺失值和质量标记，附 activity、assay、document 原始响应链接。可将记录中的 SMILES 再用于本地证据检索。不同协议不自动合并，也不按返回顺序认定药效强弱。

靶点候选最多展示 20 项，过多时请细化名称或使用 ID。SMILES 限制为 2000 字符 / 200 个原子；测量最多浏览前 10020 条，界面显示来源总数。ChEMBL 响应缓存在 `artifacts/discovery-cache/`，记录哈希和读取时间；缓存不代表最新数据库内容。在线失败与零命中分开提示，SMILES 查询失败时可保留本地结果。依据 [ChEMBL 官方接口说明](https://chembl.gitbook.io/chembl-interface-documentation/web-services/chembl-data-web-services) 实现。

结构命中、靶点测量关联与专利实施例证据是不同层次；新入口尚不能自动从任意分子或靶点生成完整竞对专利路线。

## 验证与科学边界

```sh
python -m pytest -q
python -m phase0.sar.validate
```

当前测试套件包含 177 项测试；新增覆盖 SMILES 校验、立体信息、本地查询不联网、靶点消歧、分页、限定值及失败处理。完整测试与页面入口均已验证。CI 配置在 Python 3.10 / 3.12 上运行测试及离线页面生成；本地通过不等同于远端 CI 或科学验收通过。

冻结的 21 条规则未依据留出结果调参。既有诊断中，开发案例生成 8 条候选，目标关键词命中 1/3；独立案例生成 2 条候选，命中 0/2。这是代理指标，不能视为真实召回率。规则分值不是概率，MCS 高亮不是药效团或因果证明，数值关联不能直接证明作者动机。

`artifacts/validation/` 保存数据/规则哈希、FACTS 快照、候选及复核表。人工复核需要填写 yes/no、复核人和理由；未完成时真实指标为 null。相同快照保留复核内容，变化后旧表归档。目前只有一个独立程序，`release_ready` 保持 false。可选 LLM 叙述路径有模拟测试，尚无真实模型性能评测。

尚未实现的产品能力包括：通用 PDF 结构 OCR、任意活性表自动抽取、自动跨专利路线与经证据确认的研发意图。当前索引最多显示 120 个有效结构；OCR 标题漏检和结构解析失败不表示原文不存在对应内容。未测量脑暴露、选择性或毒性时，不对这些方向作结论。

## 从检索结果追溯来源文档和专利

在分子或靶点的测量结果中点击“解析本页来源文档与专利候选”。服务重新读取该查询页的测量关联，按 ChEMBL 文档 ID 去重并查询文档元数据。卡片区分论文、专利、其他及待核实文档，展示标题、作者、年份、期刊、摘要和 DOI / PubMed（有数据时）。

仅当文档类型为 PATENT 且 patent_id 可解析为完整公开号时，提供“核实并加载专利”。不会从论文标题猜测专利，不补猜 A1/B2 后缀。加载失败保留待核实候选；加载成功进入现有专利工作台，并按原始专利页面的家族 ID 归组。同族公开及各自的来源链仍保留，家族缺失时不强行合并。

“为什么找到这份文档 / 专利”可展开查看入口、分子或靶点 ID、关联测量、文档和查询快照。加载后的“家族与来源”及下载的专利 JSON 也保留来源链。候选来自当前浏览会话中已解析的测量页，不是全库专利清单，刷新页面会清空会话候选。没有专利命中与文档服务失败明确区分，不返回固定案例。

接口：`POST /api/discover`，请求示例 `{"mode":"documents","entity":"target","id":"CHEMBL4247","offset":0}`；复用活动查询的分页限制，每次最多解析当前页 20 条测量涉及的文档。此关联不等于实施例映射、专利权利要求覆盖或研发演化证明。
